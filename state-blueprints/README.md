# XC State Blueprints

These state blueprints define distinct Wisconsin and Minnesota XC products built on the same intelligence model as Michigan without duplicating Michigan content. Each state must maintain its own trail inventory, regional taxonomy, official-source registry, state-specific copy, metadata, schema, and SEO intent.

Shared engine concepts: modeled snow score, surface-state model, morning/midday/afternoon decision windows, source confidence, and authorized grooming-provider adapters.
